# MindDiary repository guidance

Preserve unrelated user and concurrent work.

Pushes, GitHub issue or PR mutations, tags, releases, and publication require explicit user authorization unless already authorized in the conversation.

For implementation and validation, follow **Development and checks** in [CODING_STANDARDS.md](CODING_STANDARDS.md). For all repository work, consult its **Task authorities** table and load matching authorities when changing or relying on their contracts.
