## AD-001: Logo 设计 — "绝对原点 (The Core)"

**决策日期**: 2026-04-19 (v1.7.1)
**状态**: ✅ 已确定
**决策者**: 人类 + Antigravity

**决策**: 使用实心圆 + 三段弧线的极简几何 Logo。
**理由**: 符合 "安静的焦点中心" 理念；在 16px~512px 全尺寸范围内可辨识。
**替代方案**: 文字 Logo、叶片形状 — 均因过于具象或小尺寸不清晰而放弃。

## AD-002: 品牌色系 — Zen Forest

**决策日期**: 2026-04-19 (v1.7.0)
**状态**: ✅ 已确定
**决策者**: 人类 + Antigravity

**决策**: 以 `#0F766E` 深松绿为 accent，`#F6F7F4` 暖灰白为 canvas。
**理由**: 绿色传递自然、成长感；暖灰白避免纯白的冷硬感；符合 "低压力" 调性。
**替代方案**: 蓝色系（过于工具化）、暖棕色系（过于复古）。

## AD-003: Tailwind vs Vanilla CSS 共存策略

**决策日期**: 2026-04-20
**状态**: ✅ 已确定
**决策者**: GPT-5.4 Thinking + 人类

**决策**: 采用方案 C — 混合共存并设立严格物理边界。
**规则**: 
- **Tailwind 只负责**: 布局 (`flex/grid`)、尺寸 (`w/h/max`)、间距 (`p/m/gap`)、定位 (`absolute/z-index`)、响应式 (`sm/md`) 等低语义结构。
- **CSS 变量负责**: 所有颜色、边框、阴影、层级结构、状态 (hover/focus)、动画时长、暗色模式适配。
- **强制约束**: 严禁在组件中直接使用 `bg-blue-*`, `text-gray-*` 等 Tailwind 默认颜色集。
**理由**: 避免迁移成本过高，同时消除 "无边界混用" 导致的视觉碎片化。通过剥离颜色的 class 控制，保障 Zen Forest 品牌调性在深浅两套皮肤下的健壮性。

## AD-004: App Icon 配色

**决策日期**: 2026-04-20
**状态**: ✅ 已确定
**决策者**: GPT-5.4 Thinking + 人类

**决策**: 采用方案 A — 保持主品牌图标的浅底设计，提升描边厚度与对比度。
**补充策略**: 保持 "低压力、克制" 为主系统，在 QA 中若发现特定平台 (如 Windows 任务栏) 下辨识度仍受损，则仅针对特定尺寸的 `.ico` 生成加深派生版，不分裂主图标范式。
**理由**: 既遵循了 `brand.md` 避免高饱和背景的降噪理念，又通过调整几何线条对比度改善了跨平台可用性。

## AD-005: Welcome 页设计方向

**决策日期**: 2026-04-20
**状态**: ✅ 已确定
**决策者**: GPT-5.4 Thinking + 人类

**决策**: 采用方向 重设计-A — 极简首屏。
**骨架设计 constraint**: 
- 结构: `Logo` → `一句话价值主张` → `主 CTA` → `3 个低调证明项`
- 视觉: 没有任何 emoji，无紫色，无大面积插图。纯粹、安静。
**理由**: "低压力" 不仅仅是颜色变浅，更是认知负载降低。首屏的唯一任务是建立 "安全与信任"，而不是介绍产品的所有 capability。极简首屏最符合 "Action first, noise last"。
