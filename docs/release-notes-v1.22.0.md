# MindDiary v1.22.0（待发布）

本次更新改善多科目章节规划和连续录入错题的体验。

## 新增与改进

- 科目进度改为紧凑科目导航与独立章节工作区，支持搜索、筛选和章节管理；切换科目时保留各自的筛选、滚动位置和未提交草稿。章节完成操作统一使用“完成”列标题与逐章复选框，与今日任务操作明确区分。章节加入今日后，可在原行查看“已加入”状态并撤销，再次加入时无需离开页面；操作同步更新今日安排数量，并保持当前科目、筛选、滚动和焦点。
- 错题支持“添加并继续”，连续录题时保留科目、清空上一题内容并聚焦下一题；普通添加和编辑继续保留原有保存方式。

## 修复

- 修复末页错题删除或移出筛选后出现空列表的问题。
- 修复快速切换错题筛选时旧结果覆盖新结果的问题；列表读取失败时保留当前结果并提供重试。

## 今日任务与数据保护

科目页仅直接撤销由该页加入、属于当前日期和对应科目章节、未开始且未经后续修改的任务。已开始、完成、跳过、经过编辑或含有专注记录等重要关联的任务会保留，并提示前往今日安排处理。旧版本加入的任务或用户自行创建的任务也采用保守处理。撤销失败时保留真实关联状态，允许重试。

本次不新增 SQLite 迁移，schema 8 保持不变。SQLite 与 browser fallback 使用相同的安全撤销条件。

这是待发布文案；当前版本元数据仍为 v1.21.1，正式发布准备时再同步版本号与应用内更新说明，并执行打包和安装器检查。
