# MindDiary Logo Refresh — Quiet Orbit

## Design Intent

Quiet Orbit is a refinement of the original The Core identity. It keeps the most important recognition elements:

- Central solid circle: the user's focus and personal learning core.
- Three surrounding arcs: long-term growth cycles, reflection, and protected progress.

The redesign avoids adding fashionable visual elements. The goal is a symbol that remains recognizable after years of product evolution.

## Brand Meaning

MindDiary is not a pressure-driven productivity tool. It is a quiet companion for long learning cycles.

The mark communicates:

- Focus without anxiety.
- Progress through repeated small actions.
- A protected personal learning space.
- Local-first ownership of one's learning journey.

## Visual Changes

Compared with the previous version:

- Reduced core size slightly to create more breathing room.
- Increased stroke weight for better 16px–32px recognition.
- Changed arc endings to rounded terminals for a calmer human feeling.
- Preserved the Zen Forest color system and single-color adaptability.

## Usage

The logo must continue to use:

- `src/components/Logo.tsx` as the UI source.
- `public/images/logo.svg` as the pure SVG source.
- `public/images/app-icon.svg` as the application icon source.

No shadows, gradients inside the mark, text inside the symbol, or decorative effects should be added.
