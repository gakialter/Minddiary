# MindDiary 用户指南

这份指南面向普通考研用户，只说明当前应用里已经实现的功能。

## 如何写日记

1. 在左侧栏进入「写日记」。
2. 默认会打开今天的日记。应用长时间保持打开时会在本地日期变化后自动跟随新的今天；如果你从「日历」或「搜索」明确选择历史日期，则会继续停留在该历史日期。
3. 标题可以不填，在正文区写学习记录即可。
4. **CodeMirror 6 Live Preview 单编辑面**：编辑器提供即时排版渲染，在输入时直接呈现格式效果，当光标进入语法标记区域时才会展开标记字符。底层始终使用标准纯文本 Markdown 存储，不存在私有格式锁定。
5. **排版格式与快捷键**：支持 Markdown 常用语法，以及白名单受控的加粗（Ctrl/Cmd+B，`**文本**`）、下划线（Ctrl/Cmd+U，`++文本++`）、高亮（Ctrl/Cmd+Shift+H，`==文本==`）与预设文字颜色（如 `{color:green}文本{/color}`）。
6. **选区悬浮工具栏**：鼠标划选文字时，会在选区上方浮现轻量格式栏，可快速点击加粗、下划线、高亮、选择颜色，或唤起「AI 润色」。
7. **编辑历史**：支持完整的编辑器级撤销（Ctrl/Cmd+Z）与重做（Ctrl/Cmd+Shift+Z / Cmd+Y）。
8. 需要固定格式时，点击模板按钮插入默认模板，或进入「管理模板」新建自己的模板。
9. 右上角可以选择当天心情；右侧「图片附件」可以上传、拖拽图片，图片会压缩后保存到本地。
10. **自动保存**：输入过程中会自动静默保存；也可以随时按 Ctrl/Cmd+S 手动保存。
11. 如果今天有待完成的日记任务，手动保存一篇有效日记后，应用会询问是否关联并完成该任务。有效日记指正文至少 20 个有效非空白字符。
12. 自动保存、修改心情、保存标签、上传图片和番茄钟的一句话专注复盘不会自动完成日记任务。
13. **AI 汇总**：配置 AI 后，可以点击顶部的「AI 汇总」让小研总结当前日记。
14. **AI 选区润色**：划选正文后，在悬浮工具栏中选择「AI 润色」，支持四种操作：
    - **润色表达**：提升文字通顺度与自然度，保持原意和语气；
    - **精简**：删除冗余字句，保留核心信息；
    - **纠正语病**：仅纠正病句、错别字、标点与明显表达问题；
    - **保持原意改写**：提供更清晰的另一种表达方式，不补充额外事实。
    - **使用与数据规则**：仅将用户划选的目标连续文字（限制单行段落、不超过 4000 字符）发送给配置的 AI 模型，不发送日记全文；AI 返回候选后仅供预览，绝不会自动覆盖原文；用户必须显式点击「应用」才会替换选区；若在生成或预览期间原文已被修改，旧候选自动失效且禁止应用；应用后可随时通过编辑器撤销（Ctrl/Cmd+Z）恢复原样；跨段落、标题、列表、表格、链接、代码块等复杂 Markdown 结构不支持划词润色。
15. 点击「分享」可以生成一张日记分享卡片 PNG。

## 如何给日记贴标签

1. 先进入「标签管理」创建标签。
2. 标签可以设置名称、颜色、图标、展示样式和纹理。图标只支持 emoji 或 1-4 个 Unicode 短符号；不支持上传图片、自定义 SVG、远程图片或本地路径。
3. 回到「写日记」，在编辑器上方的标签区域点击标签即可选中，再次点击可取消。
4. 需要取消所有标签时，点击「清空」。
5. 进入「搜索」后，可以按标签筛选过往日记。

## 如何使用番茄钟和正计时

1. 进入「番茄钟」。
2. 选择模式：专注、短休、长休、自定义或正计时。
3. work、自定义和正计时模式下，可以在开始前选择今日 `todo` / `doing` 任务；也可以保持「不绑定任务」。
4. 任务选择可以随时清空。已完成或已跳过的任务不会用于启动新的专注。
5. 任务有关联科目时，系统会建议该科目；如果你手动改过科目，后续切换任务不会强行覆盖你的选择。
6. 没有选择科目时，会记录为未分类专注。
7. 点击「开始专注」或「开始正计时」开始。绑定的 `todo` 任务会进入 `doing`，`doing` 任务保持进行中。
8. 运行中可暂停、继续或重置。活动倒计时执行重置时，会提示这会放弃当前尚未保存的专注记录。
9. 自定义模式可设置 1-120 分钟。
10. 正计时适合不确定时长的学习，至少计时 1 分钟后才可点击「结束并保存」。
11. 专注或自定义倒计时运行至少 1 分钟后，可以点击「提前结束并保存」。确认框会展示实际专注时长和最终计入统计的分钟数。
12. 暂停时间不会计入提前保存的有效专注时长；保存成功后不会自动进入短休。
13. 保存失败时，会话会保持暂停状态，可以再次尝试保存。
14. 「进入全屏专注」会打开 Zen 专注界面，Zen 全屏中会显示当前任务、科目和模式，也有同样的提前保存入口。
15. 有效专注结束后，系统会记录到统计中。未绑定任务时仍显示原有沉淀入口：写入今日日记、添加错题，或仅保存专注。
16. 绑定任务时，结算会显示任务、科目、实际专注时长和当前任务状态。你可以选择「标记任务完成」或「继续进行」，任务不会自动完成。
17. 可以填写一句话复盘并写入对应日期的日记；空复盘不会写入。如果当天还没有日记，结算弹窗会在应用内询问是否创建日记，取消后专注记录和任务结算仍保留。
18. 也可以跳过复盘、仅保存专注记录，或继续使用「添加错题」入口。
19. 非番茄钟页面会显示悬浮 Widget，可以拖动位置，点击可回到番茄钟。
20. 设置页还可以开启结束音效、结束弹窗和专注白名单提醒。

## 如何记录错题与复习

### 记录与管理错题

1. 进入「错题本」，点击「+ 添加错题」展开录入表单（再次点击可收起）。
2. 选择科目，填写问题/知识点、答案/解析和备注。
3. 备注支持加粗、高亮、下划线和预设颜色等受控排版。
4. 题目图片与答案图片使用不同区域存储；两区都支持上传、粘贴和拖拽，每张图片最大 10MB。
5. 已有图片可以在题目与答案两个区域之间移动。历史错题图片默认属于题目图片。
6. 保存后，错题会出现在下方列表中。列表里的答案和备注默认折叠隐藏。
7. 点击「查看答案」后，才会展开显示答案、备注、答案图片及复习评分。
8. 列表支持搜索、按科目筛选、按掌握状态（全部 / 未掌握 / 已掌握）筛选，也可以一键查看「今日待复习」。
9. 已经掌握的错题可以标记「彻底掌握」移出到期池；需要重新复习时，可以点击「重新加入计划」。

### 到期复习（SM-2 记忆算法）

1. 点击错题本顶部的「到期复习」，进入今日到期错题的针对性复习流程；当前选中的科目筛选会限制复习范围。
2. 界面展示题目与题目图片，思考后点击「查看答案」。
3. 根据回忆难易程度选择复习评分（忘记、困难、良好、容易），系统将依据艾宾浩斯记忆规律与 SM-2 算法动态计算下次复习间隔与掌握状态。
4. 如果本次复习对应一个明确关联的今日 review task，SM-2 评分保存成功后会自动完成该任务。
5. 如果同一错题存在多个 active review task，应用会提示你选择一个完成，不会自动批量完成。

### 独立「日常复盘」（无放回轮次刷题）

1. 点击错题本顶部的「日常复盘」，打开独立于 SM-2 算法的全局高频复盘窗口。
2. **设置每日题量**：选择科目并输入「每日题量」（例如每天 30 题或 50 题），点击「保存」。
3. **无放回轮次机制**：系统默认将本科目全部错题（包含未掌握与已掌握错题）生成随机复习队列。一轮之内每道题目只出现一次，每天复习题目不重复。
4. **跨日连续执行**：未完成的轮次可以跨日继续进行，次日打开时自动延续本轮剩余题目，不会强行重置进度。
5. **进度清晰可见**：界面实时展示「今日：已完成 / 每日题量」、「本轮：已完成 / 本轮总数」以及「剩余题量」，预计所需天数清晰可控。
6. **显式开启下一轮**：整轮题目过完后，界面会提示「本轮已完成」；系统不会自动重新洗牌，必须由用户显式点击「开始下一轮」才会开启新的抽题轮次。
7. **与 SM-2 严格隔离**：日常复盘的核心目的是全局保温与高频提取，无论完成多少题，均**不会改写**任何题目的 SM-2 间隔、复习评分、掌握状态或到期时间。
8. **本地持久化**：轮次状态（题目队列、游标、今日进度、轮次 ID）实时保存在本地 SQLite 数据库中，应用重启后原样恢复。
9. **复盘操作流程**：进入后点击「开始本轮」或「开始下一轮」启动，看题后点击「查看答案」，核对完毕后点击「完成本题 / 下一题」推进；中途可随时点击「返回错题本」退出，当日达到目标后可点击「结束今日复盘」。

## 删除科目后会发生什么

1. 删除科目只会解除关联错题、专注记录和学习任务的科目归属。
2. 这些历史记录不会被删除，之后会以未分类或无科目归属的形式继续保留。

## 如何看「今日执行」看板与「数据统计」

MindDiary 有两个主要看板入口：

1. 「今日执行」：聚焦当天的学习任务推进、专注转化与行动闭环。显示 72 小时风险池、稳定记忆净增和有效专注转化率，并给出下一步行动入口。点击「查看系统依据」可以看判断原因。
2. 「数据统计」：查看连续专注天数、历史总专注时间、错题消灭率、今日待复习错题、关键日期、近 7 日专注趋势、近 90 天日记轨迹和专注分布。

「今日执行」里的今日任务区域还会显示轻量闭环指标：

1. 计划预计 / 实际任务专注：今日未跳过任务的预计分钟数，与实际绑定到今日任务的专注分钟数对比。
2. 今日任务完成率：`done / (todo + doing + done)`，跳过任务不进入分母。
3. 今日任务专注覆盖率：今天至少有一条有效专注记录的任务数 / 今日有效任务数。
4. 任务专注时长：今天绑定到今日任务的专注分钟总和。
5. 未闭环提示：提醒还未开始的 `todo`、进行中但还没有专注记录、或已经专注但还没有完成的任务；只有所有有效任务都是 `done` 时才会显示今日任务已闭环。

今日行动队列还支持三类轻量建议：

1. 风险池不为空时，可以点击「生成今日错题复习任务」，从今日到期错题中选择一条或多条；每道错题会创建一个独立 review task。
2. 今天还没有日记时，可以生成一个「写今日学习沉淀」任务。
3. 点击「AI 规划今日行动」后，AI 会生成候选任务；你可以编辑、删除、勾选部分建议，再确认创建。

### 如何使用每日复盘

1. 在「今日执行」的今日任务区域点击「每日复盘」。
2. 弹窗打开后会先读取并显示当天的确定性复盘依据；此时不会调用 AI，也不会创建、完成或修改任务。
3. 复盘依据会说明哪些本地数据被使用或未使用。日记正文、错题答案和笔记、图片与附件路径、API Key、现有任务描述不会进入 Daily Review AI 上下文。
4. 调整下一日可用时间后，点击生成，AI 才会产生解释性观察和下一日任务候选。
5. 候选可以编辑、删除、勾选或取消勾选；无效类型、时长、错题引用、重复任务或未知字段不能确认创建。
6. 点击创建时，应用会重新读取本地依据。如果上下文已变化，第一次点击会执行零写入并要求你查看更新结果后再次确认。
7. 创建过程中如果部分候选失败，已经成功的任务不会回滚或重复创建；失败候选会保留并可单独修改、重试。
8. 已创建任务使用下一本地日期、`status=todo` 和 `source=ai`，这些字段由本地应用控制。
9. 每日复盘不会自动定时运行，不会自动写日记，也不会自动创建下一日任务。
10. 如果本地日期在弹窗打开后发生变化，Dashboard 会关闭当前复盘，尚未创建的内存候选不会保留；等待新日期数据加载完成后，再重新打开每日复盘。

任务卡片上的 badge 含义：

1. 「AI 建议」表示任务由你确认后的 AI 候选创建。
2. 「关联错题 #ID」表示这个任务精确关联一条错题，复习保存成功后可结算。
3. 「关联日记 #ID」表示这个任务已经关联到一篇日记。

专注分布可以切换今日、近 7 天、近 30 天、单日和自定义日期范围。番茄钟倒计时和正计时保存的记录都会进入同一统计。

另外，「日历」页会在月视图中同时显示日记心情和专注标记；「科目进度」页可管理科目章节进度，并汇总今日投入、未清错题和已掌握错题。

## 如何管理详细章节进度

1. 进入「科目进度」并创建或选择一个科目。
2. 如果只想维护汇总进度，可以继续使用总章节数和已完成章节数。
3. 点击「管理章节」后，可添加单个章节，也可以把教材目录按一行一个章节粘贴到批量添加框。
4. 旧汇总科目首次添加详细章节时，MindDiary 会显示原汇总进度，并让你选择按原完成数标记前 N 个章节完成，或把新章节全部设为未完成。
5. 进入详细章节模式后，勾选章节会立即更新科目进度和 Dashboard；你也可以筛选全部 / 未完成 / 已完成，查看下一未完成章节。
6. 每个章节都可以重命名、补充简短说明、上移 / 下移排序或删除。删除带说明或已完成状态的章节前会要求确认。
7. 如果要退出详细章节模式，可以使用清空详细章节的明确操作；MindDiary 会把当前详细进度保留为汇总进度。

## 如何配置 AI 助手与数据隐私边界

### 配置与使用

1. 进入「设置」里的 AI 配置区域。
2. 选择预设供应商，或选择「自定义」。
3. 填写 Endpoint、API Key 和模型名称。留空则不会启用 AI 功能。
4. 预设供应商只是帮你填入常用地址和模型名，仍需要你自己的可用 Key。
5. 本地模型也可以使用，但需要提供兼容 OpenAI chat completions 格式的服务地址。
6. 如果使用自定义模型并确认它支持图片输入，请勾选「此模型支持图片输入」；未声明视觉能力时，AI 助手不会发送图片。
7. 保存后进入「AI 助手」，可以自由提问，也可以使用快捷入口：总结今日日记、错题规律分析、考考我、心理按摩、制定复习冲刺。
8. 点击快捷入口只会把提示词填入输入框，并添加可移除的上下文标签；它不会自动发送，也不会立即读取错题、日记或任务数据。
9. 你可以编辑草稿、删除上下文标签，再点击发送或按 Enter；Shift+Enter 只换行，输入法组合状态不会发送。
10. AI 助手可添加本地附件：图片支持 PNG/JPEG/WebP，文本文件支持 TXT/MD/CSV/JSON/LOG，PDF 只支持可提取文字的 PDF。
11. 扫描 PDF、OCR、Office 文件、压缩包、音频、视频、远程图片 URL、RAG 和 provider Files API 当前不支持。
12. 附件只在点击发送后传给当前配置的 AI provider；MindDiary 不会把附件正文、base64、PDF 提取文本或本地路径写入数据库、localStorage、聊天历史、自动备份或导出。
13. 浏览器端 fallback 不会调用 AI provider，也不会暴露 API Key；需要使用 Electron 客户端体验完整 AI 能力。

### AI 数据隐私与上下文契约

MindDiary 坚守本地优先与用户控制权，不同 AI 功能具有明确隔离的上下文边界（Context Contract）：

- **核心本地功能零依赖**：即使未配置任何 AI，写日记、专注计时、错题记录、到期复习、日常复盘、详细章节与数据统计等所有本地功能均完全可用，零强制联网。
- **按需网络交互**：所有 AI 功能仅在用户显式触发（点击发送对话、点击「AI 汇总」、划选文字点击「AI 润色」、点击「AI 规划今日行动」、点击「每日复盘」生成）时才会请求网络，不存在任何后台静默上传或行为追踪。
- **无直接写库权限**：AI 无法直接访问或修改本地 SQLite 数据库。所有生成内容均作为结构化候选（Candidates）呈现在前端，必须由用户审阅并明确确认后才调用本地接口写入。
- **日记选区润色（Selection Polish）**：仅发送用户在日记中划选的目标连续正文片段（限制单行段落、最多 4000 字符），不发送日记全文，不发送其他错题或学习数据。
- **日记「AI 汇总」**：仅发送当前单篇日记的正文内容，用于生成要点总结。
- **今日行动规划（Today Action）**：「今日执行」中的「AI 规划今日行动」仅读取受控的本地上下文摘要（如今日任务状态、到期错题数量与科目概况、今日日记简要引用），不发送错题答案或日记全文。
- **每日复盘（Daily Review Agent）**：复盘依据仅使用当天的确定性学习指标（任务完成数、专注时长等），严格排除日记正文、错题答案与笔记、附件绝对路径与系统敏感设置。
- **严格本地校验**：所有 AI 返回的任务与建议必须通过本地 JSON 解析与类型校验，非法类型、非法时长、未知字段或失效错题引用将被拦截；若在用户确认创建前本地上下文已变化，系统会拒绝写入并要求重新核对。
- **敏感凭据安全**：用户配置的 API Key 存储在受保护的本地配置中，导出备份或 JSON 快照时自动剔除。

## 如何备份和恢复

MindDiary 有三类导出/备份入口，作用不同：

1. 顶部「导出」：导出 PDF、Markdown 或 JSON 文件，主要用于阅读、归档或迁移部分学习数据。
2. 设置页「导出为 JSON / 从 JSON 导入」：用于手动 JSON 备份和合并导入。导出会剔除敏感字段；导入会处理日记、标签、科目、详细章节和错题。
3. 设置页「开启静默自动备份」：选择目录后，应用会在启动后和后续计划时间生成 MindDiary 专用 ZIP 灾备包，包含数据库快照、详细章节、日记附件和错题图片。

从自动备份 ZIP 恢复时：

1. 进入「设置」的「数据管理与备份」。
2. 点击「从 ZIP 恢复」并选择 MindDiary 生成的自动备份 ZIP。
3. 确认后，恢复会覆盖当前数据库、附件和错题图片。
4. 恢复完成后，按提示重启应用或刷新数据。

不要用 JSON 导入入口恢复 ZIP。自动 ZIP 恢复只接受 MindDiary 生成的受支持备份包；损坏、路径不安全、格式不匹配或未来版本的备份会被拒绝。
