# MindDiary 用户指南

这份指南面向普通考研用户，只说明当前应用里已经实现的功能。

## 如何写日记

1. 在左侧栏进入「写日记」。
2. 默认会打开今天的日记。需要记录其他日期时，进入「日历」页点击对应日期，应用会切回「写日记」。
3. 标题可以不填，在正文区写学习记录即可。正文支持 Markdown，以及工具栏里的加粗、高亮、下划线和预设颜色。
4. 需要固定格式时，点击模板按钮插入默认模板，或进入「管理模板」新建自己的模板。
5. 右上角可以选择当天心情；右侧「图片附件」可以上传、拖拽图片，图片会压缩后保存到本地。
6. 日记会自动保存；也可以按 Ctrl/Cmd+S 手动保存。
7. 如果今天有待完成的日记任务，手动保存一篇有效日记后，应用会询问是否关联并完成该任务。有效日记指正文至少 20 个有效非空白字符。
8. 自动保存、修改心情、保存标签、上传图片和番茄钟的一句话专注复盘不会自动完成日记任务。
9. 配置 AI 后，可以点击「AI 汇总」让小研总结当前日记。
10. 点击「分享」可以生成一张日记分享卡片 PNG。

## 如何给日记贴标签

1. 先进入「标签管理」创建标签。
2. 标签可以设置名称、颜色、图标、展示样式和纹理。图标只支持 emoji 或 1-4 个 Unicode 短符号；不支持上传图片、自定义 SVG、远程图片或本地路径。
3. 回到「写日记」，在编辑器上方的标签区域点击标签即可选中，再次点击可取消。
4. 需要取消所有标签时，点击「清空」。
5. 进入「搜索」后，可以按标签筛选过往日记。

## 如何使用番茄钟和正计时

1. 进入「番茄钟」。
2. 选择模式：专注、短休、长休、自定义或正计时。
3. work、自定义和正计时模式下，可以在开始前选择今日 `todo` / `doing` 任务；也可以保持「不绑定任务」。
4. 任务选择可以随时清空。已完成或已跳过的任务不会用于启动新的专注。
5. 任务有关联科目时，系统会建议该科目；如果你手动改过科目，后续切换任务不会强行覆盖你的选择。
6. 没有选择科目时，会记录为未分类专注。
7. 点击「开始专注」或「开始正计时」开始。绑定的 `todo` 任务会进入 `doing`，`doing` 任务保持进行中。
8. 运行中可暂停、继续或重置。活动倒计时执行重置时，会提示这会放弃当前尚未保存的专注记录。
9. 自定义模式可设置 1-120 分钟。
10. 正计时适合不确定时长的学习，至少计时 1 分钟后才可点击「结束并保存」。
11. 专注或自定义倒计时运行至少 1 分钟后，可以点击「提前结束并保存」。确认框会展示实际专注时长和最终计入统计的分钟数。
12. 暂停时间不会计入提前保存的有效专注时长；保存成功后不会自动进入短休。
13. 保存失败时，会话会保持暂停状态，可以再次尝试保存。
14. 「进入全屏专注」会打开 Zen 专注界面，Zen 全屏中会显示当前任务、科目和模式，也有同样的提前保存入口。
15. 有效专注结束后，系统会记录到统计中。未绑定任务时仍显示原有沉淀入口：写入今日日记、添加错题，或仅保存专注。
16. 绑定任务时，结算会显示任务、科目、实际专注时长和当前任务状态。你可以选择「标记任务完成」或「继续进行」，任务不会自动完成。
17. 可以填写一句话复盘并写入今日日记；空复盘不会写入。如果当天还没有日记，确认后会创建今日日记。
18. 也可以跳过复盘、仅保存专注记录，或继续使用「添加错题」入口。
19. 非番茄钟页面会显示悬浮 Widget，可以拖动位置，点击可回到番茄钟。
20. 设置页还可以开启结束音效、结束弹窗和专注白名单提醒。

## 如何记录错题

1. 进入「错题本」，点击「添加」。
2. 选择科目，填写问题/知识点、答案/解析和备注。
3. 备注支持加粗、高亮、下划线和预设颜色。
4. 题目图片与答案图片使用不同区域；两区都支持上传、粘贴和拖拽，每张图片最大 10MB。
5. 已有图片可以在两个角色之间移动。历史错题图片默认属于题目图片。
6. 保存后，错题会出现在列表中。列表里的答案和备注默认隐藏。
7. 点击「查看答案」后，才会显示答案、备注、答案图片和复习评分。
8. 列表支持搜索、按科目筛选、按掌握状态筛选，也可以查看「今日待复习」。
9. 点击「开始复习」会进入今日到期错题的主动复习流程；当前科目筛选会限制主动复习范围。
10. 选择复习质量后，系统会按间隔重复规则安排下次复习。
11. 如果本次复习对应一个明确关联的今日 review task，SM-2 保存成功后会自动完成该任务。
12. 如果同一错题存在多个 active review task，应用会提示你选择一个完成；不会自动批量完成。
13. 已经掌握的错题可以标记「彻底掌握」；需要重新复习时，可以点击「重新加入计划」。

## 删除科目后会发生什么

1. 删除科目只会解除关联错题、专注记录和学习任务的科目归属。
2. 这些历史记录不会被删除，之后会以未分类或无科目归属的形式继续保留。

## 如何看 Dashboard

MindDiary 有两个主要看板入口：

1. 「今日决策」：显示 72 小时风险池、稳定记忆净增和有效专注转化率，并给出下一步行动入口。点击「查看系统依据」可以看判断原因。
2. 「数据统计」：查看连续专注天数、历史总专注时间、错题消灭率、今日待复习错题、关键日期、近 7 日专注趋势、近 90 天日记轨迹和专注分布。

「今日决策」里的今日任务区域还会显示轻量闭环指标：

1. 计划预计 / 实际任务专注：今日未跳过任务的预计分钟数，与实际绑定到今日任务的专注分钟数对比。
2. 今日任务完成率：`done / (todo + doing + done)`，跳过任务不进入分母。
3. 今日任务专注覆盖率：今天至少有一条有效专注记录的任务数 / 今日有效任务数。
4. 任务专注时长：今天绑定到今日任务的专注分钟总和。
5. 未闭环提示：提醒进行中但还没有专注记录、或已经专注但还没有完成的任务。

今日行动队列还支持三类轻量建议：

1. 风险池不为空时，可以点击「生成今日错题复习任务」，从今日到期错题中选择一条或多条；每道错题会创建一个独立 review task。
2. 今天还没有日记时，可以生成一个「写今日学习沉淀」任务。
3. 点击「AI 规划今日行动」后，AI 会生成候选任务；你可以编辑、删除、勾选部分建议，再确认创建。

任务卡片上的 badge 含义：

1. 「AI 建议」表示任务由你确认后的 AI 候选创建。
2. 「关联错题 #ID」表示这个任务精确关联一条错题，复习保存成功后可结算。
3. 「关联日记 #ID」表示这个任务已经关联到一篇日记。

专注分布可以切换今日、近 7 天、近 30 天、单日和自定义日期范围。番茄钟倒计时和正计时保存的记录都会进入同一统计。

另外，「日历」页会在月视图中同时显示日记心情和专注标记；「科目进度」页可管理科目章节进度，并汇总今日投入、未清错题和已掌握错题。

## 如何管理详细章节进度

1. 进入「科目进度」并创建或选择一个科目。
2. 如果只想维护汇总进度，可以继续使用总章节数和已完成章节数。
3. 点击「管理章节」后，可添加单个章节，也可以把教材目录按一行一个章节粘贴到批量添加框。
4. 旧汇总科目首次添加详细章节时，MindDiary 会显示原汇总进度，并让你选择按原完成数标记前 N 个章节完成，或把新章节全部设为未完成。
5. 进入详细章节模式后，勾选章节会立即更新科目进度和 Dashboard；你也可以筛选全部 / 未完成 / 已完成，查看下一未完成章节。
6. 每个章节都可以重命名、补充简短说明、上移 / 下移排序或删除。删除带说明或已完成状态的章节前会要求确认。
7. 如果要退出详细章节模式，可以使用清空详细章节的明确操作；MindDiary 会把当前详细进度保留为汇总进度。

## 如何配置 AI 助手

1. 进入「设置」里的 AI 配置区域。
2. 选择预设供应商，或选择「自定义」。
3. 填写 Endpoint、API Key 和模型名称。留空则不会启用 AI 功能。
4. 预设供应商只是帮你填入常用地址和模型名，仍需要你自己的可用 Key。
5. 本地模型也可以使用，但需要提供兼容 OpenAI chat completions 格式的服务地址。
6. 如果使用自定义模型并确认它支持图片输入，请勾选「此模型支持图片输入」；未声明视觉能力时，AI 助手不会发送图片。
7. 保存后进入「AI 助手」，可以自由提问，也可以使用快捷入口：总结今日日记、错题规律分析、考考我、心理按摩、制定复习冲刺。
8. 点击快捷入口只会把提示词填入输入框，并添加可移除的上下文标签；它不会自动发送，也不会立即读取错题、日记或任务数据。
9. 你可以编辑草稿、删除上下文标签，再点击发送或按 Enter；Shift+Enter 只换行，输入法组合状态不会发送。
10. AI 助手可添加本地附件：图片支持 PNG/JPEG/WebP，文本文件支持 TXT/MD/CSV/JSON/LOG，PDF 只支持可提取文字的 PDF。
11. 扫描 PDF、OCR、Office 文件、压缩包、音频、视频、远程图片 URL、RAG 和 provider Files API 当前不支持。
12. 附件只在点击发送后传给当前配置的 AI provider；MindDiary 不会把附件正文、base64、PDF 提取文本或本地路径写入数据库、localStorage、聊天历史、自动备份或导出。
13. 今日决策页的「AI 规划今日行动」会读取受控、裁剪后的本地上下文，例如今日任务、到期错题、科目列表和今日日记引用。
14. AI 输出必须通过本地 JSON 解析和 schema 校验。非法类型、非法时长、无效错题引用、重复 active 任务等会被标记，不能直接确认创建。
15. AI 不会直接创建、完成、跳过、删除或修改任务；只有你确认选中建议后，才会用普通今日任务接口逐条创建。
16. 浏览器端 fallback 不会调用 AI provider，也不会暴露 API Key；需要使用 Electron 客户端体验完整 AI 能力。

AI 可能产生不准确建议，请结合自己的复习计划判断。API Key 会以敏感字段处理，不会在备份导出中明文保留。

## 如何备份和恢复

MindDiary 有三类导出/备份入口，作用不同：

1. 顶部「导出」：导出 PDF、Markdown 或 JSON 文件，主要用于阅读、归档或迁移部分学习数据。
2. 设置页「导出为 JSON / 从 JSON 导入」：用于手动 JSON 备份和合并导入。导出会剔除敏感字段；导入会处理日记、标签、科目、详细章节和错题。
3. 设置页「开启静默自动备份」：选择目录后，应用会在启动后和后续计划时间生成 MindDiary 专用 ZIP 灾备包，包含数据库快照、详细章节、日记附件和错题图片。

从自动备份 ZIP 恢复时：

1. 进入「设置」的「数据管理与备份」。
2. 点击「从 ZIP 恢复」并选择 MindDiary 生成的自动备份 ZIP。
3. 确认后，恢复会覆盖当前数据库、附件和错题图片。
4. 恢复完成后，按提示重启应用或刷新数据。

不要用 JSON 导入入口恢复 ZIP。自动 ZIP 恢复只接受 MindDiary 生成的受支持备份包；损坏、路径不安全、格式不匹配或未来版本的备份会被拒绝。
