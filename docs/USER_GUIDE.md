# MindDiary 用户指南

这份指南面向普通考研用户，只说明当前应用里已经实现的功能。

## 如何写日记

1. 在左侧栏进入「写日记」。
2. 默认会打开今天的日记。需要记录其他日期时，进入「日历」页点击对应日期，应用会切回「写日记」。
3. 标题可以不填，在正文区写学习记录即可。正文支持 Markdown，以及工具栏里的加粗、高亮、下划线和预设颜色。
4. 需要固定格式时，点击模板按钮插入默认模板，或进入「管理模板」新建自己的模板。
5. 右上角可以选择当天心情；右侧「图片附件」可以上传、拖拽图片，图片会压缩后保存到本地。
6. 日记会自动保存；也可以按 Ctrl/Cmd+S 手动保存。
7. 配置 AI 后，可以点击「AI 汇总」让小研总结当前日记。
8. 点击「分享」可以生成一张日记分享卡片 PNG。

## 如何给日记贴标签

1. 先进入「标签管理」创建标签。
2. 标签可以设置名称、颜色、图标、展示样式和纹理。图标只支持 emoji 或 1-4 个 Unicode 短符号；不支持上传图片、自定义 SVG、远程图片或本地路径。
3. 回到「写日记」，在编辑器上方的标签区域点击标签即可选中，再次点击可取消。
4. 需要取消所有标签时，点击「清空」。
5. 进入「搜索」后，可以按标签筛选过往日记。

## 如何使用番茄钟和正计时

1. 进入「番茄钟」。
2. 选择模式：专注、短休、长休、自定义或正计时。
3. 专注前可以选择科目；没有选择科目时，会记录为未分类专注。
4. 点击「开始专注」或「开始正计时」开始，运行中可暂停、继续或重置。
5. 自定义模式可设置 1-120 分钟。
6. 正计时适合不确定时长的学习，至少计时 1 分钟后才可点击「结束并保存」。
7. 专注或自定义倒计时运行至少 1 分钟后，可以点击「提前结束并保存」。确认框会展示实际专注时长和最终计入统计的分钟数。
8. 暂停时间不会计入提前保存的有效专注时长；保存成功后不会自动进入短休。
9. 保存失败时，会话会保持暂停状态，可以再次尝试保存。
10. 「进入全屏专注」会打开 Zen 专注界面，Zen 全屏中也有同样的提前保存入口。
11. 活动倒计时执行重置时，会提示这会放弃当前尚未保存的专注记录。
12. 有效专注结束后，系统会记录到统计中，并弹出沉淀入口：写入今日日记、添加错题，或仅保存专注。
13. 非番茄钟页面会显示悬浮 Widget，可以拖动位置，点击可回到番茄钟。
14. 设置页还可以开启结束音效、结束弹窗和专注白名单提醒。

## 如何记录错题

1. 进入「错题本」，点击「添加」。
2. 选择科目，填写问题/知识点、答案/解析和备注。
3. 备注支持加粗、高亮、下划线和预设颜色。
4. 题目图片与答案图片使用不同区域；两区都支持上传、粘贴和拖拽，每张图片最大 10MB。
5. 已有图片可以在两个角色之间移动。历史错题图片默认属于题目图片。
6. 保存后，错题会出现在列表中。列表里的答案和备注默认隐藏。
7. 点击「查看答案」后，才会显示答案、备注、答案图片和复习评分。
8. 列表支持搜索、按科目筛选、按掌握状态筛选，也可以查看「今日待复习」。
9. 点击「开始复习」会进入今日到期错题的主动复习流程；当前科目筛选会限制主动复习范围。
10. 选择复习质量后，系统会按间隔重复规则安排下次复习。
11. 已经掌握的错题可以标记「彻底掌握」；需要重新复习时，可以点击「重新加入计划」。

## 删除科目后会发生什么

1. 删除科目只会解除关联错题、专注记录和学习任务的科目归属。
2. 这些历史记录不会被删除，之后会以未分类或无科目归属的形式继续保留。

## 如何看 Dashboard

MindDiary 有两个主要看板入口：

1. 「今日决策」：显示 72 小时风险池、稳定记忆净增和有效专注转化率，并给出下一步行动入口。点击「查看系统依据」可以看判断原因。
2. 「数据统计」：查看连续专注天数、历史总专注时间、错题消灭率、今日待复习错题、关键日期、近 7 日专注趋势、近 90 天日记轨迹和专注分布。

专注分布可以切换今日、近 7 天、近 30 天、单日和自定义日期范围。番茄钟倒计时和正计时保存的记录都会进入同一统计。

另外，「日历」页会在月视图中同时显示日记心情和专注标记；「科目进度」页可管理科目章节进度，并汇总今日投入、未清错题和已掌握错题。

## 如何配置 AI 助手

1. 进入「设置」里的 AI 配置区域。
2. 选择预设供应商，或选择「自定义」。
3. 填写 Endpoint、API Key 和模型名称。留空则不会启用 AI 功能。
4. 预设供应商只是帮你填入常用地址和模型名，仍需要你自己的可用 Key。
5. 本地模型也可以使用，但需要提供兼容 OpenAI chat completions 格式的服务地址。
6. 保存后进入「AI 助手」，可以自由提问，也可以使用快捷入口：总结今日日记、错题规律分析、考考我、心理按摩、制定复习冲刺。

AI 可能产生不准确建议，请结合自己的复习计划判断。API Key 会以敏感字段处理，不会在备份导出中明文保留。

## 如何备份和恢复

MindDiary 有三类导出/备份入口，作用不同：

1. 顶部「导出」：导出 PDF、Markdown 或 JSON 文件，主要用于阅读、归档或迁移部分学习数据。
2. 设置页「导出为 JSON / 从 JSON 导入」：用于手动 JSON 备份和合并导入。导出会剔除敏感字段；导入会处理日记、标签、科目和错题。
3. 设置页「开启静默自动备份」：选择目录后，应用会在启动后和后续计划时间生成 MindDiary 专用 ZIP 灾备包，包含数据库快照、日记附件和错题图片。

从自动备份 ZIP 恢复时：

1. 进入「设置」的「数据管理与备份」。
2. 点击「从 ZIP 恢复」并选择 MindDiary 生成的自动备份 ZIP。
3. 确认后，恢复会覆盖当前数据库、附件和错题图片。
4. 恢复完成后，按提示重启应用或刷新数据。

不要用 JSON 导入入口恢复 ZIP。自动 ZIP 恢复只接受 MindDiary 生成的受支持备份包；损坏、路径不安全、格式不匹配或未来版本的备份会被拒绝。
