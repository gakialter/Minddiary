## P1/P2 Risk Templates

No P1 task traceability risk was confirmed in the audited v1.13.0 task path.

P2 risk: accidental future divergence between SQLite and fallback task semantics.

- Minimal fix: keep `tests/studyTaskParity.test.ts` and add one fixture per new task field or lifecycle rule.
- If not fixed: Electron and browser/dev behavior can silently differ, causing recommendations or delete semantics to pass one environment and fail another.
- If fixed incorrectly: tests can overfit timestamp formatting or implementation details instead of user-visible behavior.
- Recommended version: v1.13.1 for parity test additions, v1.13.2 for any behavior change.
- Acceptance standard: same input fixture yields identical full query rows after controlled timestamps, plus the same order and projected nulling semantics after deletion.
- Rollback: revert the focused test/fix files; no schema rollback required.
